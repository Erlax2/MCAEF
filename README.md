# Minecraft Comes Alive Villager skin x Epic Fight Compatibility (MCAEF)

A compatibility addon between **Minecraft Comes Alive (MCA Reborn)**
and **Epic Fight**.

Allows you to select and customize a Villager skin for MCA Mod while having Epic Fight, removing all the MCA rendering restrictions and adapting Epic Fight's animations to the Villager Skin. Also adds some fixes to MCA NPCs

## Features

- MCA Villager-style player skins with Epic Fight animations
- MCA faces, eyes and blinking
- MCA hair
- MCA clothing
- MCA body and genetics customization
- MCA player editor compatibility
- Automatic handling of MCA's Epic Fight renderer blacklist
- MCA villager body and clothing compatibility with EFMCA
- Fixes for Epic Fight-animated MCA NPCs
- Correct sleeping animations for MCA villagers
- Correct bed orientation for sleeping MCA villagers

## Compatibility

### Version 1.0.0

- Minecraft 1.20.1
- Forge 47.4.4+
- MCA Reborn 7.6.28 beta 10
- Epic Fight 20.14.17+
- EFMCA 1.1 supported for MCA villagers using Epic Fight

## Installation

Install this mod alongside:

- Minecraft Comes Alive / MCA Reborn
- Epic Fight

No manual changes to MCA's `playerRendererBlacklist` are required.

MCAEF automatically handles MCA's built-in Epic Fight rendering
restriction while the compatibility mod is installed.

EFMCA is optional for the player compatibility features and is used
for Epic Fight integration with MCA villagers.
